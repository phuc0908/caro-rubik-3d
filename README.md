# Caro Rubik 3D

A local two-player Gomoku game built with Three.js. Connect five across cube faces and twist one Rubik’s Cube layer per player per match.

## Run locally

From the repository root, run `python -m http.server 8000 --directory dist`, then open [localhost:8000](http://localhost:8000).

Hover over a tile and use the arrow keys to preview a layer twist. Press Esc to cancel or click an empty tile to apply the twist and place your mark.
